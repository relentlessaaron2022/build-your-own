# Bamboo pages: public launch and recognition agenda

Ten sales pages share one Cloudflare project. Ten different pages are not ten
independent search rankings, and publishing alone does not guarantee traffic.

## 1. Public launch

- Connect the owner's Cloudflare Pages account to this GitHub repository.
- Use `microsites/sites/bamboo-sheets` as the project root, no build command,
  and `dist` as output. Choose the approved source branch.
- Verify all ten actual public URLs on desktop and mobile. Check images,
  navigation, size/color controls, and call-to-order links.
- Record the verified project/URLs in registry.json. Keep Beacons checkout deferred.
- Confirm the current offer, prices, stock, fiber label, ordering arrangements,
  shipping/collection, and returns before promoting specific product claims.

## 2. Search foundation

- Choose the permanent public hostname and a primary product page.
- Add that page's real canonical URL, useful page title, description, social
  preview image, crawlable internal links, and a sitemap using the actual host.
- Remove noindex from the selected primary page when it is ready for search.
  Keep closely related campaign variants noindex initially. Only index additional
  pages once their content serves a distinct search need and adds real value.
- Verify domain ownership in Google Search Console and Bing Webmaster Tools;
  submit the sitemap and inspect the primary URL for indexing problems.
- Add accurate product/business structured data only where the required facts
  are verified. Do not invent reviews, thread counts, certifications, or stock.

## 3. Measurement before promotion

- Enable basic traffic analytics in the owner's hosting/analytics account.
- Connect the existing call-click event interface to a real event collector if
  call-click reports are needed. Update privacy/consent handling as applicable.
- Use consistent UTM links for Pinterest, Instagram, Facebook, Threads, TikTok,
  YouTube, Etsy, and Beacons where those services permit outbound links.
- Record actual paid phone orders with each page's displayed BS-* order code.
  A visit or button click is not a paid sale; phone attribution is approximate.

## 4. Initial discovery campaign

- Produce original pins showing the product, a bedroom palette, and a useful
  buying detail. Link each pin to its matching public page with campaign tags.
- Connect the Pinterest account and appropriate bedding boards. Review sample
  pins and verify one live publish before enabling unattended automation.
- Share relevant links through the owner's existing social profiles and posts,
  using authorized accounts and the platform's supported link placements.
- Avoid flooding channels with ten near-identical posts. Test a manageable set
  of distinct messages and images, then expand based on actual response.

## 5. Ongoing useful content

- Publish substantive answers to real shopper questions: Queen vs King fit,
  exact set contents, available colors, verified fiber composition, and care
  instructions from the actual product label.
- Improve product photos and dimensions; distinguish illustrative lifestyle
  imagery from documentation of the exact item.
- Link useful content to the primary product page and related offers. Earn
  relevant mentions rather than buying links or mass-producing duplicate pages.

## 6. Friday revenue review

Review sessions by source, search impressions/clicks, Pinterest outbound clicks,
call clicks, actual paid orders, revenue, costs, and refunds. Compare pages with
enough traffic to make a useful comparison. Improve weak steps and invest more
effort in offers and creative that produce paid sales. Search indexing and
rankings may take time and are not promised on a fixed schedule.
