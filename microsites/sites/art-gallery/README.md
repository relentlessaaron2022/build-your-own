# Relentless art gallery: five campaign pages

Pages: collection, wall-art, meaningful-gifts, phone-wallpapers, and heritage. All purchase calls to action lead to https://relentlessaaron.net/gallery/ with page-specific campaign parameters. These pages collect no payments and send no Telegram messages.

The source catalog records 58 real works extracted from the public WordPress gallery on November 3, 2026. Actual artwork images remain on the owner's WordPress site, an external dependency. Prices are omitted so the source gallery presents current offers. No artwork was invented or substituted.

Regenerate with `node build.mjs`. Cloudflare: use this folder as root, no build command, output dist. No Cloudflare project is connected. Campaign pages retain noindex and no analytics collector is connected.

GitHub Actions validates the source. Local browser QA became unavailable when the execution workspace disconnected; remote image availability and visual appearance still need verification in a deployed browser.
