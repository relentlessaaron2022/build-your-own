# The GitHub Report: Money Series (20 videos)

**Promise of the series:** one popular repo per video, one way it pays, what it costs, and the license line you can't cross.
**Host:** the Relentless University avatar in the studio. **Look:** our GitHub Report format (Vox boards, word-timed captions, the tools-and-dollars counter, the Relentless University mark).
**Deliverables per video:** one horizontal (16:9, 6–8 min) and one vertical (9:16, 45–60 s). That's 40 files.

---

## What the top GitHub channels do (and what we take)

| What works for them | How we use it |
|---|---|
| **Numbered series** ("GitHub Trending Weekly #60", "Top 10 Trending Repos") build a habit | Every video is numbered: *Money Series #1–#20* |
| **Money in the title** ("5 GitHub repos that print $$$") gets the click | Titles open with the money: *"$500 a Client: …"* |
| **Repo name on screen in the first 5 seconds** | Cold open shows the repo card and the price tag together |
| **Speed:** a new visual every 3–5 s | Vox boards already cut on the word; keep every board under 8 s |
| **Listicles** win search | Episodes 19–20 are roundups that point back to 1–18 |
| **Where they're weak:** no business plan, no license warnings, no "first client" step | **Our edge:** every video ends with *The License Line* and *Your First Client* |

**Fixed structure (horizontal):**
1. **Hook (0:00–0:15):** the repo, the money, the cost ("$0 software, $300 a setup").
2. **What it is (0:15–1:00):** one card, three facts.
3. **The money model (1:00–3:30):** who pays, what they pay for, how much.
4. **What it costs you (3:30–4:30):** hardware, API bills, time.
5. **The License Line (4:30–5:30):** what you can and can't sell. This is our signature segment.
6. **Your first client (5:30–6:30):** the exact offer and the message to send.
7. **Recap + newsletter + sign-off.**

**Vertical cut:** the hook, the one money line, the license warning in one sentence, and "full breakdown on the channel."
